## 📱 开户流程 (App 版)

### 步骤 1: 下载 App (5 分钟)

```
1. 打开 App Store / Google Play
2. 搜索"富途牛牛"
3. 下载安装
4. 打开 App
```

---

### 步骤 2: 注册账号 (5 分钟)

```
1. 点击"立即开户"
2. 输入手机号码
3. 获取验证码
4. 设置登录密码
5. 完成注册
```

---

### 步骤 3: 身份认证 (10 分钟)

```
1. 选择证件类型
   - 中国内地居民身份证
   - 香港身份证
   - 护照
   - 其他

2. 拍摄证件
   - 正面清晰照片
   - 反面清晰照片
   - 确保证件在有效期内

3. 人脸识别
   - 按提示做动作
   - 确保光线充足
   - 摘下眼镜/口罩
```

---

### 步骤 4: 填写资料 (10 分钟)

```
1. 基本信息
   - 姓名
   - 出生日期
   - 国籍
   - 性别

2. 联系信息
   - 邮箱
   - 地址 (重要！)
   - 电话

3. 职业信息
   - 职业
   - 行业
   - 职位
   - 公司名称

4. 财务信息
   - 年收入范围
   - 投资经验
   - 资金来源
```

---

### 步骤 5: 上传住址证明 (5 分钟)

```
1. 选择文件类型
   - 水电费单
   - 银行账单
   - 信用卡账单
   - 政府信件
   - 保险单

2. 拍摄/上传
   - 清晰完整
   - 3 个月内
   - 显示姓名和地址

3. 提交审核
```

**内地用户注意**：
- 如地址是中国内地，需额外上传境外地址证明
- 或选择"无境外地址证明"选项 (可能无法开户)

---

### 步骤 6: 签署协议 (5 分钟)

```
1. 阅读并同意
   - 客户协议
   - 隐私政策
   - 风险披露
   - 费用表

2. 电子签名
   - 手写签名
   - 确认提交
```

---

### 步骤 7: 风险测评 (5 分钟)

```
1. 完成问卷 (约 10-15 题)
2. 评估风险承受能力
3. 确定投资经验等级

题目示例：
- 您的投资经验？
- 您能接受的最大亏损？
- 您的投资目标？
```

---

### 步骤 8: 提交审核 (1-3 工作日)

```
1. 确认所有信息
2. 提交申请
3. 等待审核
4. 接收结果通知

审核时间：
- 正常：1-3 工作日
- 快速：当天 (工作时间内)
- 慢速：3-5 工作日 (资料不全)
```

---

## 💰 入金流程

### 审核通过后

#### 方式 1: 银行转账 (推荐) ⭐⭐⭐⭐⭐

```
1. 登录富途 App
2. 点击"交易" → "入金"
3. 选择币种 (港币/美元)
4. 获取收款账户信息
5. 通过银行转账
   - 网银转账
   - 柜台转账
   - ATM 转账
6. 上传转账凭证
7. 等待到账 (1-3 工作日)
```

**最低入金**：
- 港股：HK$10,000 (建议)
- 美股：$1,000 (建议)
- 实际：无最低限制

---

#### 方式 2: FPS 转数快 (香港用户) ⭐⭐⭐⭐⭐

```
1. 登录富途 App
2. 点击"交易" → "入金"
3. 选择"FPS 转数快"
4. 扫描二维码/输入号码
5. 通过银行 App 转账
6. 即时到账
```

**优点**：
- ✅ 即时到账
- ✅ 无手续费
- ✅ 24/7 可用

---

#### 方式 3: 银证转账 (内地用户) ⭐⭐⭐

```
1. 需要香港银行账户
2. 从内地汇款至香港
3. 从香港银行转入富途

注意：
⚠️ 内地汇款有限额 (每人每年 5 万美元)
⚠️ 需要外汇额度
⚠️ 手续费较高
```
