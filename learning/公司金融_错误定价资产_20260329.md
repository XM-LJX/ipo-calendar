## 💡 核心概念：被错误定价的资产

### 什么是错误定价？

```
错误定价 = 市场价格 ≠ 内在价值

两种情况：
1. 低估：市场价格 < 内在价值 → 买入机会
2. 高估：市场价格 > 内在价值 → 卖出/做空机会
```

---

## 🔍 如何寻找错误定价资产

### 方法 1: 基本面分析 ⭐⭐⭐⭐⭐

```
核心指标：
✅ PE (市盈率) - 与同行/历史对比
✅ PB (市净率) - 与同行对比
✅ PS (市销率) - 成长股适用
✅ PEG (市盈率增长比) - 成长股估值
✅ 自由现金流 - 真实现金流
✅ ROE (净资产收益率) - 盈利能力
```

**低估信号**：
- PE < 行业平均 30%+
- PB < 1 (破净)
- PEG < 1
- 自由现金流持续为正
- ROE > 15%

---

### 方法 2: 相对估值法 ⭐⭐⭐⭐

```
对比维度：
1. 同行业对比
   - 选择 3-5 家可比公司
   - 对比 PE/PB/PS 等指标
   - 找出估值最低的

2. 历史对比
   - 对比公司历史估值区间
   - 找出处于历史低位的

3. 跨市场对比
   - A 股 vs 港股 vs 美股
   - 同公司不同市场估值差异
```

---

### 方法 3: DCF 现金流折现 ⭐⭐⭐⭐⭐

```
核心公式：
内在价值 = Σ(未来自由现金流 / (1+折现率)^n)

步骤：
1. 预测未来 5-10 年自由现金流
2. 选择合适折现率 (8-12%)
3. 计算终值
4. 折现求和
5. 与当前市值对比
```

**低估信号**：
- 内在价值 > 当前市值 30%+
- 安全边际充足

---

### 方法 4: 催化剂分析 ⭐⭐⭐⭐

```
催化剂类型：
✅ 业绩超预期
✅ 重组/并购
✅ 政策利好
✅ 新产品发布
✅ 管理层变更
✅ 行业周期反转
✅ 分析师上调评级
```

**最佳机会**：
- 低估 + 催化剂 = 高确定性机会

## ⚠️ 风险提示

### 价值陷阱

```
看似低估，实际有问题的公司：
❌ 连续亏损
❌ 现金流为负
❌ 高负债
❌ 行业衰退
❌ 管理层有问题
❌ 财务造假嫌疑
```

**避免方法**：
- 深入基本面分析
- 查看现金流
- 关注负债率
- 跟踪 insider 交易

---

### 时间成本

```
低估可能持续很久：
⏳ 1 年：正常
⏳ 3 年：可能
⏳ 5 年+：少数

应对：
✅ 用闲钱投资
✅ 分散投资
✅ 长期持有
✅ 定期复盘
```

---

### 机会成本

```
持有低估资产时：
⚠️ 可能错过其他机会
⚠️ 资金被占用
⚠️ 心理压力大

应对：
✅ 分散投资 5-10 只
✅ 设置时间止损 (2 年)
✅ 保持耐心
```
